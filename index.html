Тест: выход из Instagram в браузер

Открой эту ссылку из директа Instagram на iPhone. Нажимай кнопки по очереди, после каждой возвращайся в Instagram и пиши, что произошло.

1. Схема Instagram (главная ставка)

Должен появиться диалог Instagram «открыть во внешнем браузере», потом браузер со страницей «✅ Открылось».

2. x-safari-https

Старый способ «сразу Safari». По статьям Instagram его режет с 2025.

Открыть в Safari · способ 2

3. Через Chrome

Сработает только если стоит Chrome.

Открыть в Chrome · способ 3

4. Автоматически, без нажатия

Страница сама пробует уйти во внешний браузер при загрузке. Если ничего не случится — значит, автоматом нельзя, только по кнопке.

Проверить автопереход · способ 4
